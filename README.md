# 🚀 Team Task Manager

A modern full-stack Team Task Manager application built using Flask, JWT Authentication, SQLAlchemy, and Railway deployment.

---

# 🌐 Live Demo

🔗 https://web-production-78641.up.railway.app

---

# ✨ Features

- Secure JWT Authentication
- Role-Based Access
- Task Creation
- Task Completion Tracking
- Dashboard Analytics
- Modern Responsive UI
- Cloud Deployment with Railway

---

# 🛠️ Tech Stack

## Frontend
- HTML5
- CSS3
- JavaScript

## Backend
- Flask
- Flask-JWT-Extended
- SQLAlchemy
- Flask-Bcrypt
- Flask-CORS

## Database
- SQLite

## Deployment
- Railway

---

# 📊 Functionalities

## Authentication
- User Registration
- User Login
- JWT Token Generation

## Dashboard
- Project Count
- Total Tasks
- Completed Tasks
- My Tasks

## Task Management
- Create Tasks
- Update Task Status
- Mark Tasks as Completed

# 🚀 Local Setup

## Clone Repository

```bash
git clone https://github.com/prinithlejose153-cmyk/team-task-manager.git
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Application

```bash
python -m backend.app
```
